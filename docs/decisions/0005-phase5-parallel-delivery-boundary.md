# ADR 0005：Phase 5 并行交付边界

- 日期：2026-07-15
- 状态：已批准
- 批准依据：项目负责人明确确认“Phase 5 可只依赖 Phase 1/3，可以闭环”

## 背景

Phase 4 的确定性算法实现和自动化门禁已经通过，但真实来源许可、固定 source commit/release、Palworld Steam build ID、游戏版本和配方真实性仍待人工验收。该验收是配种事实进入真实数据生产发布以及 Phase 6 配种器闭环的必要条件。

Phase 5 的登录、概览、帕鲁列表、账号和数据状态不执行配种算法，也不需要真实配种配方。它只读取 Phase 1 已验证的 RLS/RPC 与共享契约，以及 Phase 3 产出的脱敏库存；开发和验收只连接本地或预览 Supabase。

## 决策

批准 Phase 5 独立于 Phase 4 的真实数据人工验收并行实施，边界如下：

1. Phase 5 的前置依赖只包含 Phase 1 的 RLS/RPC/共享契约和 Phase 3 的脱敏库存。
2. Phase 5 只能使用本地或预览 Supabase 与明确标注的合成 fixture，不得访问生产凭证、真实存档或生产数据库。
3. 目录显示和搜索只能读取绑定世界当前发布的版本化游戏目录；目录未配置或存在未知 ID 时必须显式展示稳定状态，不能在 Web 端硬编码游戏事实。
4. Phase 4 的 `real_data_acceptance=pending` 和 `production_publish=blocked` 保持不变。
5. Phase 6 以及任何真实配种数据的生产发布继续受 Phase 4 人工验收阻塞；本决定不授权部署、远程推送或生产变更。

## 结果

Phase 5 可以在上述非生产边界内完成独立验收。阶段状态检查必须同时核对本记录、正式规格、实施计划和项目状态文档；缺失本记录或边界措辞不一致时，Phase 5 不得标记为进行中或已完成。
