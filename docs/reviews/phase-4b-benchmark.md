# Phase 4B 确定性配种引擎性能基准

- 日期：2026-07-15
- Python：3.12.13
- 命令：`cd apps/agent && uv run python scripts/benchmark_breeding_engine.py`
- 数据：固定种子 `20260714` 生成的纯虚构分层配方图，不含真实游戏或存档数据
- 测量：`time.perf_counter` 墙钟时间；`tracemalloc` Python 峰值分配内存

## 固定限制

```text
最大代数                 4
最大展开节点             200,000
超时                     5,000 ms
每种类路线状态           128
每被动覆盖桶分配状态     16
评分前候选               256
输出路线                 12
```
