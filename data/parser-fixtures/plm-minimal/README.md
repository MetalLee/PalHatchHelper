# Synthetic PlM parser fixture

`Level.gvas.base64` is a text-encoded, fully synthetic GVAS property tree. It
contains invented GUIDs, the fictional player `Ada`, fictional Pals, and the
fictional guild `Ironpaw`. No bytes originate from a production save.

The fixture was generated by the synthetic `build10World` builder in
`8tp/palhelm` at commit
`e099e8afe4823d6cf6b371e5e3938955e5a1becd` (Apache-2.0), whose explicit test
comments identify every GUID and record as invented. Its decoded SHA-256 is
`ff7665e4f70d30eb31a747c229cf1bd348e050e535b8fe37397d3fe8072158a1`.

Parser tests wrap these bytes in a minimal `PlM/0x31` container and load a
test-only Oodle ABI shim that copies the already-uncompressed body. The shim is
built in a temporary test directory and is never committed or used in
production. Production PlM parsing still requires an operator-supplied,
SHA-256-pinned Oodle library.
